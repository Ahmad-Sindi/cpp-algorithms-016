# Algorithm Challenge #16 – Rectangle Area Through Diagonal and Side

## 🧮 Problem Description
Write a C++ program that calculates the **area of a rectangle** when you are given:
- The **length of one side (a)**
- The **length of the diagonal (b)**

The program should use the **Pythagorean theorem** to determine the other side, then calculate the area.

---

## 🧠 Formula
If:
- `a` = one side  
- `b` = diagonal  

Then the other side `c` = √(b² - a²)

So the **area** = `a * c`

---
💡 Example

Input:
Enter the side length: 3  
Enter the diagonal length: 5  

Output:
The area of the rectangle is: 12
